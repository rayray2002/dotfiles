# Environment notes (shared across my machines)

Linked to `~/.claude/CLAUDE.md` on every machine from `claude/CLAUDE.md` in the dotfiles
repo, so edits here (including memory added with `#`) land in the repo: run `dots-sync`
to share them.

## Machines (ssh aliases)
- `mac`: my laptop (macOS). Dotfiles at `~/dotfiles`.
- `xarm` (a.k.a. `salep`): USC lab Linux box, 1 GPU.
- `glamor_panda_ray`: Franka/Panda robot workstation (glamor-citrine), 2 GPUs. Shared lab
  machine: don't touch the `franka_glamor` account or robot services.
- `snoopy`: USC GPU server, 8x RTX A6000 under Slurm. No root. My login is `borueihu`.
- `ray-desktop`: home desktop.

## Dotfiles
- Everything in `~` that is a symlink into `/nix/store` is generated by home-manager from
  the dotfiles repo. Edit the repo, never the generated file, then `dots-sync "msg"`
  (commits, applies here, pushes, updates the other machines). `dots-status` shows every
  machine's state. See `README.md` and `docs/` in the repo.
- Shell is zsh. Available everywhere: rg, fd, bat, eza, jq, gh, uv, `mamba` (micromamba),
  direnv, zoxide (`z`), lazygit, tmux.

## snoopy (Slurm GPU server)
- Rootless Nix: interactive logins enter an env where `$HOME` is `/scr/borueihu/nixhome`;
  the real home is `/home/borueihu` (~15 GB quota). Put data, checkpoints, caches and
  environments on `/scr/borueihu/...`, never in the home directory.
- Never run GPU work on the login shell; `nvidia-smi` there only works inside a job.
  - `gpus`: which GPUs are free and who uses the rest.
  - `sgpu [n] [time]`: interactive shell on GPUs (1 GPU uses `phd`, 2-3 use `partition-1`).
  - `snew NAME`: new sbatch from the usual template; submit with `sbatch NAME.sbatch`.
  - `sq` my jobs, `sqa` all jobs, `slog [job]` follow a log, `sk` cancel, `shist` history.
  - Limits: `phd` QoS = 1 GPU / 16 CPUs per job; `partition-1` = 3 GPUs per user.
  - Other people's jobs share the machine: request only what a job needs.
- Python envs: micromamba/conda root `/scr/borueihu/miniforge3`; uv venvs inside projects.
  `HF_HOME=/scr/borueihu/cache/huggingface`. wandb is logged in via `~/.netrc`.

## Secrets
- Never print, log or commit credentials (`~/.netrc`, tokens, keys). Shared ones are
  age-encrypted in the repo (`secrets/*.age`) and decrypted at activation; manage them
  with `dots-secret`.
